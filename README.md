# global_chat

Requirements: Node.js server with express, axios and discord.js

add this line in the minetest.conf file of each server: ````secure.http_mods = chat_sync````
Replace "Servidor_2" for "Servidor_1", "Servidor_2" or "Servidor_3" in the init.lua file of the mod. Make sure that each minetest server has a unique "Servidor_ID" in mods/chat_sync/init.lua
